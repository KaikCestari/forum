            Do sensor ao alerta

            Três linguagens, cada uma no que faz melhor. O Java coordena, o Rust processa o volume e o Python aprende com os dados.

              Executar de novo

              Refaz todo o caminho. Com novos dados, o gerador cria outro cenário, com outros eventos e outro ruído, e a IA precisa encontrá-los sem saber onde estão.

              Importar dados reais

              Envie as leituras dos seus sensores em CSV. O AquaML grava tudo no banco H2, substitui o conjunto atual e refaz a análise inteira com os mesmos modelos.

              Colunas: timestamp e station_id, mais os parâmetros que você tiver (ph, do_mgl, temp_c, turbidity_ntu, conductivity_uscm, nitrate_mgl, phosphorus_mgl, coliforms_nmp). Também aceita ; com vírgula decimal, datas dd/mm/aaaa hh:mm e cabeçalhos como “Data/Hora”, “Estação”, “OD (mg/L)” ou “Fósforo total”. Os dias precisam de pelo menos 6 leituras, como as de sensores contínuos.

              IQA mês a mês

              Média mensal do IQA de cada estação, calculada por uma consulta SQL no H2 sobre a série diária da última análise. Passe o mouse para ver o pior dia e os dias anormais.

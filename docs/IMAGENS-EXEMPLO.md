# Imagens de exemplo

Ficam em `frontend/public/exemplos/` e aparecem na tela **Imagens**, em "Usar uma imagem de exemplo".
Um clique preenche o formulário com a imagem, o tipo (foto ou satélite) e a estação sugerida dos dados
de exemplo. Depois é só enviar para a IA ler.
